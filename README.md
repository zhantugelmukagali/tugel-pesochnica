# TUGEL Studio · конструктор и испытания

Браузерная 3D-песочница модульной робототехники. Соберите собственного робота из деталей, задайте соединения, добавьте груз и препятствия, затем запустите программу испытания в физическом движке.

Текущий интерфейс — **конструктор v2**. JavaScript, Three.js, Rapier и Vite работают локально в браузере; для запуска не нужны серверная часть, аккаунт или API-ключи. ИИ и LLM/LMM в этой версии не подключены.

## Собрать робота

В режиме **«Конструктор»** доступны:

- Приводной модуль, корпус, шарнирный модуль, груз и неподвижное препятствие.
- Размещение деталей на поле, перенос и поворот инструментами сцены.
- Точные координаты, углы, размеры, масса и закрепление в инспекторе.
- Жёсткие соединения и поворотные шарниры между соседними гранями; настройка оси и предела шарнира.
- Дублирование, удаление, автоматическое соединение соседей и отмена/повтор изменений.
- До 40 деталей в проекте, включая груз и препятствия. Рабочие границы по X/Z — ±5 метров.

Выберите деталь слева и нажмите на площадку. Для связи расположите её грань рядом с гранью другого модуля, выберите тип соединения и вторую деталь. По умолчанию перенос и поворот действуют на всю связанную сборку. Снимите «Перемещать всю сборку», чтобы редактировать отдельную деталь. Значительное перемещение отдельной детали или изменение её геометрии может удалить несовместимые связи и относящиеся к ним команды; отмена восстанавливает предыдущую сборку.

Проверка проекта учитывает границы поля, пересечения корпусов, пол, допустимость связей и ссылки команд на существующие детали. Невалидное редактирование не заменяет рабочий проект.

## Готовые роботы

В библиотеке есть три редактируемых шаблона с программами испытания:

| Шаблон | Что исследовать |
| --- | --- |
| **Сочленённый вездеход** | Изгиб корпуса, движение к точке и поворот |
| **Модульный манипулятор** | Три управляемых шарнира на закреплённом основании |
| **Складная платформа** | Подъём крыльев и перемещение базы |

Можно начать с пустого проекта. Шаблоны используют те же детали, соединения и редактор, что и собственные конструкции.

## Испытать конструкцию

В режиме **«Испытание»** команды выполняются по очереди:

1. Перемещение выбранного робота в точку X/Z; цель можно указать на площадке.
2. Поворот робота на заданный угол.
3. Поворот выбранного шарнира в пределах его ограничения.
4. Ожидание заданного времени.

Команды можно добавлять, переставлять и удалять. Настраиваются скорость привода, гравитация и темп симуляции. Доступны запуск, пауза, одиночный шаг и сброс. При возврате в конструктор восстанавливается исходная сборка: физический тест не переписывает её координаты.

Панель результатов показывает время, пройденное расстояние, максимальную скорость и контактные пары. Отчёт завершённых запусков экспортируется отдельно от проекта в JSON. Смена конструкции и программы требует нового испытания.

## Что рассчитывает физика

Rapier рассчитывает движение и вращение твёрдых тел, тяжесть, контакты, трение и ограничения соединений. Приводы действуют ограниченной силой, шарниры управляются моторами. Контроллер перемещения планирует путь с учётом препятствий и проверяет выполнение команд по состоянию симуляции.

У модели есть конкретные упрощения:

- Тяга привода задаётся на плоскости. Полноценной модели шин, подвески и дифференциального привода нет; это не ограничение всех тел только горизонтальным движением.
- Коллайдеры проще визуальных моделей. Колёса используют сферические контактные элементы; винты, декоративные панели и кабели не добавляют физических деталей.
- Не моделируются гибкость корпусов, разрушение, реальные батареи, электроника, нагрев и предельные характеристики конкретного сервопривода.
- Соединения задаются в конструкторе. Самостоятельная стыковка и расстыковка физических модулей не реализованы.

Успешный тест подтверждает поведение этой модели. Перед сборкой железа параметры нужно сверять с измерениями приводов, соединителей и материалов.

## Управление и файлы

| Действие | Управление |
| --- | --- |
| Выбор / перенос / поворот / соединение | `V` / `G` / `R` / `C` |
| Показать всю сборку | `F` |
| Удалить выбранную деталь | `Delete` |
| Дублировать | `Ctrl+D` / `⌘D` |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Shift+Z` (также `⌘`) |
| Сохранить | `Ctrl+S` / `⌘S` |
| Перейти к испытанию или пуск/пауза | `Space` |
| Отменить выбор места / цели | `Esc` |

Камера вращается перетаскиванием; колесо мыши меняет масштаб. Есть виды сверху и спереди, отключение сетки и снимок сцены в PNG.

**Сохранить** записывает один проект в `localStorage` текущего браузера. Новая запись заменяет предыдущую. Меню файла содержит загрузку, импорт и экспорт. JSON v2 хранит сборку, соединения, настройки и программу испытания, но не промежуточное состояние запущенного физического мира. Для обмена между устройствами используйте экспорт: облачная синхронизация пользовательских проектов отсутствует.

Импорт ограничен 1 MiB и проверяет схему, параметры и геометрию. Старые сцены v1 не импортируются автоматически; их файлы и прежний ключ хранилища не изменяются. История отмены действует в текущем сеансе и в экспорт не входит.

## Запуск и проверки

Требуется Node.js 22.12+ или актуальная совместимая версия Node.js 24. Для 3D нужен браузер с WebGL2 и WebAssembly.

```bash
git clone https://github.com/zhantugelmukagali/tugel-pesochnica.git
cd tugel-pesochnica
npm ci
npm run dev
```

Откройте адрес Vite из терминала.

```bash
npm test
npm run build
```

Статическая сборка находится в `dist/`; конфигурация Sites — в `.openai/hosting.json`. GitHub Actions проверяет тесты и сборку. DOM-тесты используют настоящий код интерфейса с заменой WebGL-сцены и границы физического движка: они проверяют интеграцию действий, но не заменяют визуальную проверку в браузере.

```text
src/
  builder.js          интерфейс конструктора и испытаний
  builder.css         оформление интерфейса
  builder-scene.js    3D-модели, камера, выбор и инструменты
  project.js          схема v2, редактирование и валидация сборки
  assembly-edit.js    согласованный перенос и поворот связанной сборки
  workspace-store.js  история, локальное сохранение и JSON
  physics.js          Rapier, приводы, контакты и выполнение команд
  scenarios.js        программы для готовых роботов
tests/                модели, физика, сохранение и DOM-интеграция
```

Ранние модули `kinematics.js` и `swarm.js` и их тесты сохранены для исследований. Они не являются текущим интерфейсом конструктора.
